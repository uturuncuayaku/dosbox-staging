# Agent Rules

- **File Creation Header**: When creating a new file, always include an "Antigravity" header at the very top to differentiate that it was created by an agent (e.g., `// Created by Antigravity`).
- **New File Location & Exclusion**: Place any new helper/script files under `docs/` and add their path to `.git/info/exclude` so Git does not track or upload them to GitHub PR branches.
