# Agent Rules

- **File Creation Header**: When creating a new file, always include an "Antigravity" header at the very top to differentiate that it was created by an agent (e.g., `// Created by Antigravity`).
- **Clickable Links**: Always include line numbers (e.g., `#L10-L20`) and format file paths, code symbols (classes, functions, structs) as clickable github-style markdown links using the `file://` scheme (e.g., `[filename](file:///absolute/path/to/file)`).
